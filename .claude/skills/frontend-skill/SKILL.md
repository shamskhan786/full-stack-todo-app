# Frontend Skill – Pages, Components, Layout, Styling

## Instructions

1. **Page & Layout Structure**
   - Create responsive pages using Next.js App Router
   - Define reusable layouts (header, footer, main content)
   - Mobile-first and desktop-friendly design

2. **Components**
   - Build reusable UI components (buttons, cards, modals, forms)
   - Ensure proper props and state management
   - Optimize for re-rendering efficiency

3. **Styling**
   - Use Tailwind CSS or modular CSS for consistent styling
   - Implement spacing, typography, and color schemes effectively
   - Apply hover, focus, and animation effects for interactivity

## Best Practices
- Keep components small and reusable
- Use semantic HTML for accessibility
- Optimize asset sizes and loading
- Ensure responsive design across devices
- Use clear class naming and maintainable structure
